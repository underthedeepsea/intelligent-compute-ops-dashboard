# 资源录入

Gateway 左侧只有一个 **资源录入** 入口，也可打开 `/gateway/?view=catalog`。页内切换 **直接录入**、**批量导入**、**已录入服务目录**。配置持久保存到后台；这些关系不代表实时流量或运行健康。

直接录入一次登记整项推理服务：选择 PRD / DR / STG / DEV 环境、团队、一个或多个业务、模型，按合并推理或 P/D 分离填写实例。团队、业务、模型和集群可选已有资源，也可同页新建。每个 P/D 组可登记多个 P、D 和可选 Router，合并服务可登记多个 COMBINED 实例。

每个实例填写集群、K8s Namespace、LWS 或 Deployment、工作负载名称和地址引用；可登记多个配置 Node。配置节点标明“未验证运行位置”，不会生成 Pod、Node UID、Pod UID 或观测时间。UUID 与稳定代码由服务器生成，界面不要求手工填写身份。API Key 外部引用与模型授权在原 API Key 管理页面维护，整项保存保留已有 Key、授权和额外业务关联。

保存只发送一次整项请求。目录支持搜索、整项编辑、查看本服务关系图、完整只读 JSON 导出和配置复制 CSV。编辑保留所有已存在的 P/D 组、实例、业务关联及历史身份；移除已保存的组或实例将其退休，历史运行成员与采集绑定保留。已有旧环境不会被迁移；未登记部署配置的旧实例可原样保留，修改该实例时需补齐配置。

批量导入使用服务模板，和监控 CSV 分开。一行对应一个实例，同环境与服务别名聚合整项，同组别名聚合 P/D 组。上传或粘贴 UTF-8 CSV，点击“校验全批”查看服务预览和逐行错误；展开逐行修正后必须重新校验，旧摘要失效。应用全批在一个后台事务中完成，任一错误全批回滚。批量只创建新服务；已有服务从目录编辑。已有父资源的 ID 可由目录导出取得，新对象使用模板别名，不人为生成 UUID。配置复制 CSV 不含运行观测，不用于覆盖已有服务；配置复制 CSV 仅支持单业务；多业务记录使用完整 JSON 查看并整项编辑，后台会明确拒绝 CSV 复制导出。历史缺少配置的单业务记录需补齐复制模板后重新校验；完整 JSON 保留所有关系和历史。

有未保存输入时，离开、返回目录或刷新会确认；取消保留草稿。提交期间禁止重复保存和页面切换。版本冲突保留草稿，核对目录并重新读取后继续。若提示“保存成功，目录刷新失败”，请用已返回 UUID 核对，避免重复创建。若网络中断提示“结果未知”，先在目录核对结果；当前草稿不能直接重发，只有核对后明确新建才开始新的请求。

**基础资源配置** 是辅助入口：可维护团队、业务、模型和集群；服务、P/D 组和 Endpoint 使用所属服务整项编辑。Node / Pod 运行成员只读，可查看历史采集信息并进入所属服务；共享 Node 先选择对应记录。运行身份由采集链路维护，配置节点不代替采集。

总览包含后台真实节点与边生成的资源关系图，保留完整授权与运行实例表。资源映射默认选取启用服务，其次模型；服务目录与整项编辑的“查看此服务关系图”使用明确服务焦点。图形动画提示已登记关系，不证明流量、吞吐或健康。监控来源、巡检与人工监控快照继续在原页面维护。

当前验收使用只读复制原目录后迁移的临时数据库和 `127.0.0.1:8770`。不会写入日常 8767/8768 或原 SQLite；本地检查不代表生产系统或真实采集验收。
