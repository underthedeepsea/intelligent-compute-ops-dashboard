# 资源与关系录入

从 Gateway 左侧的 **资源与关系录入** 进入，或打开 `/gateway/?view=catalog`。入口先展示各类型数量与资源目录，不直接展开编辑表单。点击目录中的对象进入独立配置视图；点击 **新建** 进入该类型的新建视图。配置视图可返回原类型目录。资源映射上方的 **配置当前对象** 会直接打开焦点对象；Key 焦点进入原有 Key 管理，Node 焦点进入对应 Pod 部署记录，共享 Node 时先选择具体记录。

## 建立一条完整关系

1. 录入团队、业务、模型和集群。业务选择所属团队并填写负责人。关键业务还需要正整数展示顺序。
2. 录入推理服务，选择模型和部署模式。合并部署使用 COMBINED；P/D 分离使用 SPLIT_PD。
3. P/D 分离服务先录入 P/D 组，再录入实例 / Endpoint。P 实例角色为 PREFILL，D 实例为 DECODE，路由实例为 ROUTER；实例选择同一服务的 P/D 组与部署集群。合并服务自动限定为 COMBINED，不关联 P/D 组。
4. 回到业务，勾选依赖的服务，点击 **保存业务服务关系**。资源信息和服务关系分别保存，提示会说明本次保存的是哪一项。
5. 点击 **API Key 归属与模型授权**，在原有页面登记 Key 外部引用、所属团队及业务，保存后选择授权模型。这里只保存引用与配置意图，不签发或展示原始密钥。
6. 在 **Node / Pod 部署** 中选择 Endpoint，集群自动跟随 Endpoint。填写命名空间和实际 Pod / 工作负载信息。若需要 Node 连线，填写实际 Node UID、Node 名称、Pod UID 与含时区的实际观测时间。不得用名称代替 UID，也不要用本次保存时间代替观测时间。尚未采样时可保留 Node 与可选身份/时间为空，只登记工作负载。
7. 保存后点击 **查看此资源的更新映射**，在 Demo 图形拓扑与调用关系中查看同一份持久目录。业务依赖、模型授权与部署位置均属于配置关系，不证明真实请求、健康或执行端生效。

## 编辑与冲突

目录中的类型卡片或类型选择器用于切换资源类型，点击对象进入配置。配置页有未保存的输入或业务服务勾选时，返回目录、切换 Gateway 页面或点击刷新会先询问是否放弃；取消则保留当前草稿。环境从当前身份授权范围选择，保存后不可迁移；父级选项按环境和部署关系过滤。已有停用关系会保留并标记，不会因隐藏选项而静默删除。当前原生入口不提供删除或停用操作。

保存使用读取记录的版本。发生版本冲突时保留表单，不自动覆盖服务器。先记录需要保留的输入，再点击 **重新读取（放弃本页草稿）**，核对最新记录后重新修改。业务元数据保存不会自动提交服务勾选；服务关系保存也不会自动提交上方字段。

如果提示“保存已成功，但刷新未完成”，写入已完成，请重新选择该记录核对，避免把创建重复提交。新建与保存仅供 `catalog_admin`；`operator` 可浏览记录，不能提交写入。当前身份无可选授权环境时，请由管理员配置环境范围。

## 与已有页面的关系

集群监控来源、巡检配置及 CSV 导入继续在 **监控数据管理** 页面维护。高级后台保留；原有七列 Demo 拓扑、调用关系模式、监控来源和动画机制未改动。目录表单不会部署工作负载、生成真实观测身份或更改监控来源。

新版入口的完整浏览器回归使用独立 `127.0.0.1:8768` 与全新 `/private/tmp/gateway-demo-entry-v1.sqlite3` 的合成测试数据；目录/独立配置导航与生命周期还用内存 API fixture 检查。没有向日常 `8767` 目录写入测试记录。这些检查不代表已接入生产或真实采样系统。
